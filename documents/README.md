# Bagwan document library

Imported from the live Bagwan site on 18 November 2026. Original filenames and Drive folder membership are recorded in [manifest.json](manifest.json).

The files below are ordinary Git assets. Native Google Docs were exported as DOCX. Drive shortcuts were replaced with copies of their verified target documents.

Use [source-link-map.json](source-link-map.json) to replace the original iframe and document URLs during the static-site rebuild. Folder destinations identify directories and their manifest entries; the static site must render their file lists.

`local_path` and URL-encoded `local_href` are relative to the repository/site root. Do not prepend `/` when deploying beneath a GitHub Pages repository path.
